# @spasai/web — веб-панель заведения и админка

Пока пусто: приложение появится на **Этапе 4** (панель заведения) и **Этапе 8**
(админка) согласно разделу 9 ТЗ.

Планируемый стек: React + Vite + TypeScript + TailwindCSS, Яндекс.Карты JS API.

Экраны панели заведения (раздел 5 ТЗ):

1. Регистрация: ИНН, название, адрес, категория, фото, реквизиты → на модерацию
2. Дашборд: заказы сегодня, выручка за период, сколько еды спасено
3. Создание бокса (в т. ч. повторяющегося)
4. Активные боксы: редактирование, снятие с продажи
5. Заказы: подтверждение выдачи по коду покупателя
6. Отчёты и выплаты
7. Отзывы: чтение и ответ
