# @spasai/mobile — мобильное приложение покупателя

Пока пусто: приложение появится на **Этапе 5** согласно разделу 9 ТЗ.

Планируемый стек: React Native + Expo, Яндекс.Карты MapKit, FCM/APNs.

Экраны (раздел 4 ТЗ):

1. Онбординг (3 экрана + запрос геолокации)
2. Вход по номеру телефона и SMS-коду
3. Главная — лента боксов рядом
4. Карта с пинами и боттом-шитом
5. Фильтры
6. Карточка бокса (срок годности указан явно)
7. Оформление заказа и оплата
8. Мои заказы — код выдачи и таймер
9. Профиль — «спасено еды»
10. Отзыв после получения
