# Презентация

`spasai.pdf` — документ на шесть страниц A4: зачем приложение, как работает,
экраны, что готово, деньги, техническая часть. Та же страница в вебе —
`prezentaciya.html`, открывается в браузере и печатается в тот же PDF.

`screens.png` — одна картинка со всеми десятью экранами приложения
(1816 × 1800). Для документа те же экраны нарезаны на две полосы:
`screens-1.jpg` и `screens-2.jpg`.

Панель заведения — `panel-dashboard.png`, `panel-boxes.png`,
`panel-orders.png`; в документе используется обрезанный `panel.jpg`.

В подвале документа оставлены заглушки для контактов — их надо заполнить
перед отправкой.

## Как пересобрать

Исходники страницы разделены: `_style.html` — оформление и правила печати,
`_content.html` — текст. Картинки вшиваются в HTML при сборке, чтобы файл
открывался без интернета.

```sh
# 1. Скриншоты приложения (нужны запущенные API и Expo Web)
node scripts/store-shots.mjs

# 2. Сводная картинка и полосы для документа
python3 scripts/showcase.py

# 3. Страница и PDF
node scripts/build-presentation.mjs
```

Нужны Python с Pillow и Playwright с Chromium.
