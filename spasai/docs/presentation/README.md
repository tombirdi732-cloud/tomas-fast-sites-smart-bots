# Презентация

`spasai.pdf` — шесть страниц A4: зачем приложение, как работает, экраны,
что готово, деньги, техническая часть.

## Как править текст

Сам PDF править не надо — он получается из обычной веб-страницы, и
переделать проще её.

1. Открыть **`prezentaciya-pravki.html`** в любом текстовом редакторе:
   «Блокнот», VS Code, Sublime — подойдёт что угодно. Файл маленький,
   28 КБ, картинки лежат рядом отдельными файлами.
2. Найти нужный текст и поменять. Текст всегда стоит между `>` и `<`:

   ```html
   <h2>Что это решает</h2>
        ↑ вот это меняем ↑
   ```

   Угловые скобки и всё, что внутри них, трогать нельзя — это разметка.
   Блок `<style>` в начале файла отвечает за оформление, туда лучше не
   лезть.
3. Сохранить и открыть этот же файл двойным щелчком — он откроется в
   браузере. Видно сразу, что получилось.
4. **Ctrl + P** → в поле «Принтер» выбрать **«Сохранить как PDF»**.

   Обязательно раскрыть «Дополнительные настройки» и включить
   **«Фоновая графика»** — иначе зелёная шапка напечатается белой.
   Поля оставить как есть: их задаёт сама страница.

Готово, это тот же PDF.

### Что где лежит в файле

| Раздел | Как найти |
|---|---|
| Заголовок и подзаголовок на зелёном | `<h1>` и `<p class="lead">` в начале |
| Четыре плашки под заголовком | блок `<dl class="facts">` |
| Шаги покупателя и заведения | блок `<div class="flows">` |
| Таблица готовности | `<table>` — каждая строка это `<tr>` |
| Плашки «работает» / «нужны ключи» | `<span class="chip">` |
| Чек с комиссией | `<div class="receipt">` |
| Контакты внизу | `<footer>`, оранжевые `<span class="fill">` |

### Поменять картинку

Положить новый файл рядом под тем же именем: `screens-1.jpg`,
`screens-2.jpg`, `panel.jpg`. Перезагрузить страницу в браузере.

### Убрать целый раздел

Удалить всё от `<section>` до парного `</section>` включительно.

## Файлы

| Файл | Что это |
|---|---|
| `spasai.pdf` | готовый документ |
| `prezentaciya-pravki.html` | **то, что правим** — маленький, картинки рядом |
| `prezentaciya.html` | то же самое, но картинки вшиты внутрь: один файл, который можно отправить как есть |
| `screens.png` | все десять экранов одной картинкой, 1816 × 1800 |
| `screens-1.jpg`, `screens-2.jpg` | те же экраны двумя полосами, для документа |
| `panel-*.png` | панель заведения целиком; `panel.jpg` — обрезанная для документа |
| `_style.html`, `_content.html` | исходники для пересборки скриптом |

## Пересобрать всё скриптом

Нужно, только если менялись скриншоты приложения. Требуются Python с
Pillow и Playwright с Chromium.

```sh
node scripts/store-shots.mjs        # скриншоты приложения
python3 scripts/showcase.py         # сводная картинка и полосы
node scripts/build-presentation.mjs # страница и PDF
```

Правки текста при этом надо вносить в `_content.html`, иначе сборка
затрёт `prezentaciya.html`.
