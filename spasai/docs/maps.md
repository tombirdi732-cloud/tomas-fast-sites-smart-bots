# Карта

## Что нужно от вас: один ключ

Карта в приложении — Яндекс.Карты (MapKit Mobile SDK). Это единственная
подложка, которая в России работает без оговорок: Google Maps требует
сервисов Google, а публичные тайлы OpenStreetMap для коммерческого проекта
использовать нельзя.

Ключ берётся в кабинете Яндекса:

1. [yandex.ru/dev/mapkit](https://yandex.ru/dev/mapkit) → войти через Яндекс ID;
2. подключить **MapKit Mobile SDK**, тариф **Free**;
3. скопировать ключ и положить его в `apps/mobile/.env`:

```
EXPO_PUBLIC_MAPKIT_API_KEY=ваш-ключ
```

Ключ читается на сборке, в репозиторий не попадает. После этого:

```bash
cd apps/mobile
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
```

## Про бесплатный тариф

Free-лицензия MapKit — до 25 000 MAU. Условия, под которые «Спасай»
попадает: приложение бесплатное и доступно всем, это не навигатор
и не система мониторинга, данные карты показываются на карте
и не сохраняются на своей стороне.

Ограничения, которые касаются нас напрямую: **нельзя строить маршрут
с ведением по нему** и нельзя кэшировать чужие данные. Показывать точки
выдачи и расстояние до них — можно.

Когда перерастём 25 000 MAU, придётся переходить на коммерческую лицензию;
цены Яндекс считает по DAU и публикует на странице тарифов.

## Что уже сделано

| | |
|---|---|
| Библиотека | `react-native-yamap-plus` v6 — New Architecture, config-плагин Expo |
| Версия SDK | **Lite** — только карта и метки, без поиска, маршрутов и панорам: она легче и нам хватает |
| Ключ | `EXPO_PUBLIC_MAPKIT_API_KEY`, инициализация в `src/mapkit.ts` |
| Без ключа | экран рисует схему — приложение остаётся рабочим |
| Веб | `src/mapkit.web.ts` — заглушка, нативный пакет в веб-бандл не попадает |

На карте:

- ценники вместо булавок — цена видна сразу, без нажатия;
- своя позиция — родная точка MapKit (`showUserPosition`);
- нажатие на ценник открывает карточку бокса внизу;
- увели карту в сторону — появляется «Искать здесь», поиск идёт по новому
  центру; кнопка «прицел» возвращает к своему местоположению.

### Размер APK

`libmaps-mobile.so` весит 26 МБ — это сам MapKit, деться от него некуда.
Чтобы APK можно было передать файлом, включено `useLegacyPackaging`:
нативные библиотеки в APK сжимаются, и сборка укладывается в 29 МБ вместо 55.
Плата — приложение занимает на устройстве больше и стартует чуть медленнее.
Для публикации в сторах это не нужно: там заливается AAB, и магазин сам
отдаёт устройству только нужную архитектуру.

### Android 8.0 и старше

MapKit требует `minSdkVersion 26`, поэтому минимальная версия Android
поднята с 7.0 до 8.0. Устройств на 7.x в 2026 году доли процента —
но знать об этом стоит.

## Адреса заведений

Заведение больше не вводит широту и долготу руками — на них держится весь
геопоиск, и ошибиться в них проще простого. В панели поле адреса
подсказывает варианты из реестра, а вместе с выбранной строкой
подставляются координаты и часовой пояс.

Подсказки идут через DaData (`GET /api/merchants/address-suggest`) — тем же
токеном `DADATA_TOKEN`, что и проверка ИНН. Без токена панель показывает
поля координат и объясняет, где их взять.

Точность адреса видна модератору: если реестр нашёл только улицу или
город, панель об этом предупреждает — покупатель должен понимать,
к какой двери идти.
