# Карточка приложения в RuStore

Скриншоты в этой папке сняты с работающего приложения (Expo Web,
1080×2340 — обычный размер экрана телефона), а не нарисованы в макете.

**Важно перед публикацией.** На скриншотах заведения из тестовой базы —
«Пекарня „Тёплый хлеб“», «Магазин „Продукты у дома“», «Кофейня „Полдень“».
Таких заведений не существует. Для предзаказа это допустимо как
демонстрация интерфейса, но как только подключатся первые настоящие
заведения, скриншоты надо переснять на их данных: витрина магазина не
должна обещать то, чего нет.

Скриншота карты в наборе нет: в браузере вместо Яндекс.Карт рисуется
запасная схема. Снимок карты нужно сделать с телефона на собранном APK.

Пересобрать набор — при запущенных API (`localhost:3000`) и Expo Web
(`localhost:8081`):

```sh
npm i -g playwright && npx playwright install chromium
node spasai/scripts/store-shots.mjs
```

Если Chromium уже стоит в другом месте, путь к нему задаётся
переменной `CHROMIUM_PATH`.

## Название

**Спасай** (50 символов — запас есть)

## Краткое описание (до 80 символов)

```
Еда из кафе и пекарен рядом со скидкой до 70% — вместо того чтобы пропасть
```

73 символа.

Запасные варианты:

```
Боксы еды из кафе и пекарен рядом — со скидкой до 70%
Спасайте еду от мусорки: боксы из кафе рядом дешевле в 2–3 раза
Кафе и пекарни рядом отдают вечерние боксы со скидкой до 70%
```

## Полное описание (до 4000 символов)

```
Каждый вечер кафе, пекарни и магазины списывают еду, которую не успели
продать. Она хорошая, просто её срок заканчивается завтра. «Спасай»
показывает такие боксы рядом с вами — и вы забираете их со скидкой до 70%.

КАК ЭТО РАБОТАЕТ

1. Открываете приложение и видите боксы поблизости — ближайшие сверху,
   с ценой, скидкой и расстоянием.
2. Выбираете бокс и бронируете его. Заведение придержит его для вас
   до конца окна выдачи.
3. Приходите в указанное время, называете шестизначный код — забираете
   бокс. Платите на месте, на кассе.

ЧТО ВНУТРИ БОКСА

Выпечка, готовая еда, продукты, кофе — зависит от заведения. Часть боксов
это «сюрприз»: точный состав заранее неизвестен, зато и цена в два-три
раза ниже обычной. Заведение всегда указывает категорию, вес или
количество и срок годности — до покупки видно, сколько ещё можно хранить.

ПОЧЕМУ ЭТО ЧЕСТНО

• Срок годности на каждом боксе. Просроченное продавать запрещено:
  приложение не даёт выставить бокс, у которого срок заканчивается
  раньше конца выдачи.
• Настоящая старая цена. Скидка считается от обычной цены заведения,
  а не от выдуманной.
• Отзывы только от тех, кто забрал заказ.

ВОЗМОЖНОСТИ

• Боксы рядом с сортировкой по расстоянию — от соседнего дома до
  соседнего города, если рядом пока пусто.
• Карта с булавками заведений.
• Категории: выпечка, готовая еда, кофейни, продукты.
• Избранные заведения — придёт уведомление, когда у них появится бокс.
• Отмена заказа: 15 минут после оформления или за два часа до выдачи.
• Тёмная тема.

ДЛЯ ЗАВЕДЕНИЙ

Пекарня, кофейня, столовая, магазин у дома? Списанная еда — это ваши
деньги в мусорном ведре. Подключайтесь: выставляйте боксы из панели
заведения, принимайте оплату на кассе как обычно, выдавайте заказы по
коду. Заявку можно оставить прямо на сайте — вход по Яндекс ID, из
документов нужен только ИНН.
```
