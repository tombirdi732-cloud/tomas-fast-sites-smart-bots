# Скриншоты

Снято с работающих приложений (Playwright гоняет реальные экраны против
реального API с локальной базой), а не нарисовано.

## Панель заведения и админка — `panel/`

| Файл | Что |
|---|---|
| `01-login.png` | вход по телефону |
| `02-dashboard.png` | дашборд заведения |
| `03-boxes.png` | боксы: цена, остаток, окно выдачи, срок годности |
| `04-box-form.png` | форма нового бокса |
| `05-orders.png` | заказы и выдача по коду покупателя |
| `06-staff.png` | сотрудники заведения |
| `07-staff-invite.png` | код приглашения кассира |
| `08-reviews.png` | отзывы и ответы на них |
| `09-admin-moderation.png` | модерация: заявка рядом с данными реестра ФНС |
| `10-admin-invite.png` | код приглашения заведения |
| `11-admin-suspend.png` | приостановка одобренного заведения с причиной |

Данные на скриншотах — демо-сид из `apps/api/prisma/seed.ts`, он работает
только локально: в production сид падает с ошибкой, чтобы в боевой базе
не оказалось выдуманных заведений и отзывов.
